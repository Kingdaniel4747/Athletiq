# Changelog

Alle wichtigen Änderungen an AthletiQ werden hier dokumentiert.

## Unreleased

- Vollständiges AthletiQ-Branding in Oberfläche, PWA, API, Docker und Dokumentation.
- Neuer Umschalter zwischen **Gym** und **Health**.
- Health-Bereich für Kalorien, Makros, Protein, Wasser, Barcode-Produkte und Mealie.
- Gemeinsame Ampel für Gewichtstrend, Ernährung, Trainingskonstanz und progressive
  Überlastung.
- Optionaler KI-Coach mit bestätigungspflichtigen Vorschlägen für Ernährung und
  Trainingsplan.
- Standalone `docker-compose.yml` mit fertigen GHCR-Images für AMD64 und ARM64.
- Repository auf GitHub Actions, GitHub Issues und GitHub Container Registry reduziert.
- Nicht verwendete Plattform-, Demo- und native Wrapper-Pakete entfernt.
