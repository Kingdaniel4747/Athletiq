# Changelog

Alle wichtigen Änderungen an AthletiQ werden hier dokumentiert.

## Unreleased

- Passkey-RP-ID folgt standardmäßig automatisch der geöffneten Domain und bindet Origin
  und RP-ID sicher an den jeweiligen WebAuthn-Vorgang; verständliche HTTPS-Diagnose ergänzt.
- Persönliches Vier-Schritt-Onboarding mit Startwerten, Proteinspanne, Sicherheitsgrenzen
  und adaptiver Energie-Hypothese aus ausreichend vollständigen Trends.
- Gemeinsames Tagescockpit für Workout, Kalorien, Protein, Wasser, Tagesform und Skills.
- Calisthenics-Progressionsleitern und detaillierte Logs für Assistenz, Last, Hebel,
  Bewegungsumfang, Tempo, Haltezeit, Form, RPE und Schmerz.
- Schnelles Ernährungstracking mit Favoriten, Standardportion, Ein-Tipp-Logging,
  Mahlzeiten-Vorlagen, Vortagskopie sowie Roh/Gekocht- und Datenqualitätsangabe.
- Tägliche Erholungsdaten, wöchentlicher Coach-Check-in, Körpermaße und ausschließlich
  lokal gespeicherte Fortschrittsfotos.
- Coach auf höchstens zwei priorisierte Aktionen, kleine Kalorienschritte, Schmerz-Stopp,
  Änderungsverlauf und Undo begrenzt.
- Rate-Limits sowie bestätigungspflichtige vollständige Profil-Löschung ergänzt.
- Optionale wöchentliche Push-Erinnerung für einen fälligen Coach-Check-in ergänzt.
- Vollständiges AthletiQ-Branding in Oberfläche, PWA, API, Docker und Dokumentation.
- Neuer Umschalter zwischen **Gym** und **Health**.
- Health-Bereich für Kalorien, Makros, Protein, Wasser, Barcode-Produkte und Mealie.
- Gemeinsame Ampel für Gewichtstrend, Ernährung, Trainingskonstanz und progressive
  Überlastung.
- Optionaler KI-Coach mit bestätigungspflichtigen Vorschlägen für Ernährung und
  Trainingsplan.
- Ein einziges GHCR-Image für Web-App und API sowie eine Ein-Service-Compose-Datei.
- Einmaliger Download der 1.324 Übungsbilder und Animationen in den Browser statt
  eines Medien-Containers und Serverordners.
- Repository auf GitHub Actions, GitHub Issues und GitHub Container Registry reduziert.
- Nicht verwendete Plattform-, Demo- und native Wrapper-Pakete entfernt.
